# Design System: Sevora Lab

## 1. Overview

**Creative North Star: "The Deep Space Lab"**

The Sevora Lab design system is built to reflect the vast depth of space, combining dark cosmic backdrops with precise cybernetic layouts and glowing interactive elements. The aesthetic is clean, professional, and high-performance, proving the agency's technical mastery through premium presentation and tactile details. 

We explicitly reject generic, template-like SaaS aesthetics in favor of a custom, handcrafted digital studio identity. The layout values content density, high contrast, and immersive depth layers, making the interface feel alive yet reliable.

**Key Characteristics:**
- Deep cosmic background canvas with subtle gradients and light leak glows.
- Clean grotesque display typography paired with highly legible humanist body text.
- Glassmorphic layers used purposefully for content containers to establish elevation.
- Soft, neon-colored ambient glows that react directly to user input.

## 2. Colors

The color palette represents a midnight tech aesthetic, contrasting dark voids with high-energy electric highlights.

### Primary
- **Electric Blue Glow** (#3B82F6): The primary brand color. Used for key action highlights, focal interactive states, and glowing accents.
- **Fluid Cyber-Gradient** (#1E40AF to #00D1FF): Used for main visual markers and select display text gradients.

### Neutral
- **Deep Cosmic Void** (#020617): The absolute foundation canvas. A near-black blue-tinted neutral.
- **Off-White Ink** (#F8FAFC): The primary text color. High contrast, clean, and extremely readable.
- **Muted Cyan-Border** (rgba(59, 130, 246, 0.1)): Subtle borders separating layout divisions.

### Named Rules
**The Rarity of Glow Rule.** Saturated accents and glow effects are used on ≤10% of any given screen. Their rarity is what establishes premium visual authority; over-saturating the interface turns a high-end studio into a gaming template.

## 3. Typography

**Display Font:** Outfit (with var(--font-outfit), sans-serif fallbacks)
**Body Font:** Inter (with var(--font-inter), sans-serif fallbacks)

Typography establishes authority through extreme weight and scale contrast, keeping headers tight and prose comfortable.

### Hierarchy
- **Display** (Bold 700, clamp(2.5rem, 6vw, 6rem), 1.1, letter-spacing: -0.03em): Used for primary hero headlines.
- **Headline** (Bold 700, clamp(2rem, 4vw, 4rem), 1.2, letter-spacing: -0.02em): Used for section titles.
- **Title** (Semi-Bold 600, 1.5rem, 1.4): Used for sub-sections and cards.
- **Body** (Regular 400, 1.125rem, 1.6, line-length: ~70ch): Used for paragraphs, general information, and readable copy.
- **Label** (Medium 500, 0.875rem, letter-spacing: 0.05em, uppercase): Used for tags, badges, and tiny interface instructions.

### Named Rules
**The Contrast Over Loudness Rule.** Do not set display headlines above 6rem. Visual impact is created by pairing heavy, tightly tracked display headers with lightweight, spacious body paragraphs, not by making letters massive.

## 4. Elevation

The system uses a layered glass and glowing depth philosophy. Surfaces are flat at rest, with elevation conveyed through border color shifts, translucent backdrops, and active neon glows on hover.

### Shadow Vocabulary
- **Electric Hover Glow** (`box-shadow: 0 0 20px rgba(59, 130, 246, 0.3)`): Used under buttons and badges to represent active selection or hover.
- **Subtle Ambient Depth** (`box-shadow: 0 12px 40px rgba(0, 0, 0, 0.5)`): Applied to fixed navigation or overlay modals.

### Named Rules
**The Flat-at-Rest Rule.** Containers and cards do not cast drop shadows unless hovered or in a distinct active state. Depth is generated by structural borders and backdrop-blur overlays.

## 5. Components

Components are designed to feel tactile and glowing, adapting smoothly to mobile and desktop contexts.

### Buttons
- **Shape:** Full pill shape (rounded-full / 9999px)
- **Primary:** Electric Blue backdrop (#3B82F6) with white text, using (16px 32px) padding.
- **Hover / Focus:** Transition to a deeper cobalt (#2563EB) with an electric hover glow (0 0 20px rgba(59, 130, 246, 0.3)).
- **Outline:** Double-thick border (#3B82F6) with electric text, filling on hover.

### Cards / Containers
- **Corner Style:** Rounded edges (24px / rounded-3xl)
- **Background:** Semi-translucent dark glass (rgba(255, 255, 255, 0.03)) with blur filter (12px)
- **Border:** Thin boundary line (1px solid rgba(255, 255, 255, 0.08)) that shifts to accent-color on hover.
- **Internal Padding:** Comfortably spaced (32px / p-8)

### Navigation
- **Header:** Sticky full-width top bar, shifting to a floating pill shape (rounded-full) with border (white/10) and backdrop blur (85% opacity) once scrolled.
- **Items:** Medium text weights, highlighting active paths with an accent underline and showing a subtle pill backdrop (white/4%) on hover.

## 6. Do's and Don'ts

### Do:
- **Do** respect prefers-reduced-motion by disabling translate/zoom animations and replacing them with instant or opacity-only fades.
- **Do** check contrast for body text against dark backgrounds (ensure body copy uses white/80% or white/60% instead of dark gray).
- **Do** wrap long headings using `text-wrap: balance` to prevent awkward typography orphans on mobile.

### Don't:
- **Don't** use warm, beige, cream, or sand background defaults (token colors like `--paper`, `--cream`, `--sand`, `--bone`).
- **Don't** use side-stripe borders (e.g. border-left or border-right accent strokes greater than 1px) to highlight cards or alerts.
- **Don't** apply borders and heavy drop shadows (blur >= 16px) on the same container at rest (the "ghost-card" pattern).
- **Don't** use border-radii greater than 24px on cards and containers.
- **Don't** place repetitive, identical card grids with the same size and layout recursively down the page.
- **Don't** use tiny uppercase wide-tracked eyebrows above every section as default scaffolding.
